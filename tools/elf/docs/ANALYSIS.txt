방법
- ELF32 little-endian MIPS 헤더/프로그램 헤더/섹션 범위를 먼저 확인했다.
- EUC-JIS-2004 후보 스캔만으로 결정하지 않고 Ghidra 12.1.2 및 Emotion Engine
  r5900:LE:32:default로 역어셈블/디컴파일/문자열 전체 범위의 참조를 검사했다.
- 문자 인코딩 스캔은 디버그/코드/폰트 표에서도 우연히 성공할 수 있다.
  일본어가 읽힌다는 사실과 실제 번역 가능한 화면 문구라는 사실을 구분했다.
- .rodata의 정렬되지 않은 가나 문자열도 별도로 검사했고 추가 후보는 없었다.
  압축 데이터/텍스처/다른 인코딩까지 모든 문구를 찾았다는 의미는 아니다.
- 아래 주소는 VA와 파일 오프셋을 구분한다. 코드 수정은 수행하지 않았다.

바탕화면 파일은 일본어 원본과 비교해 위 획득 문구 3개에서만 42바이트 차이가 난다.
기계어/헤더/폰트는 차이가 없다. 돈 문구는 기존에 색상 코드가 빠져 있다.

한계
이 기록은 정적 분석이다. 간접 참조/다른 실행 상태의 완전성을 증명하지 않는다.
게임에서의 글자 폭/표시 위치/획득 메시지/영상 오류/미니게임/디스크 교체는 아직
실행 검증하지 않았다. 길이 초과는 자동 재배치하지 않고 명시적으로 실패한다.
분석 프로젝트와 원시 근거는 codex-lab에만 보관한다. 운영 도구는 이를 읽지 않는다.
