자산 분류와 분석 근거
====================
저장소 내부 아카이브 생성/재검증 기능은 2026-10-24 용량 정리 때 제거했습니다.
현재 작업 순서는 ../README.txt를 참고하세요. 아래 내용은 자산을 분류한 분석 기록입니다.
메모리카드 제목 작업은 보류 상태이며 일반 빌드에 자동 적용하지 않습니다.

추가 자산 분류와 보존 범위
- mnu/shop/*.shp 25개는 SLPS 00236710이 0x214바이트로 읽고 00239158이 품목 ID 목록, +0x200의 개수, +0x208의 목록 위치 및 옵션 값으로 사용하는 상점 테이블입니다. 이름 문자열이 아니므로 원본을 보존합니다.
- bat/robo_mvs.bin은 OV02의 00A9FF50/00AB7898이 리소스 0x06020001로 읽습니다. 00A9E690이 앞의 4개 상대 오프셋을 풀고 00A9E858이 동작 분류/12바이트 레코드로 사용합니다. 번역 텍스트가 아니므로 별도 변환 도구를 추가하지 않습니다.
- jpg/dtimg의 680파일(고유 그림 343개)을 확인해 세그먼트 UI/낚시 간판/튜토리얼 이미지 25쌍에 수동 교체 경로를 추가했습니다. 나머지 인물·장면 삽화는 보존합니다. jpg/mcimg 348개는 컷신 미리보기이며 일본어 UI 문구가 별도로 박힌 후보를 찾지 못했습니다.
- mnu/pse의 TXY 3개는 별·성운·태양 이미지 8개이며, bat의 JPG 21개(고유 그림 20개)는 인물 초상과 통신 배경입니다. 번역 도구를 추가하지 않습니다. 컷신용 mdl/map/ev의 디버그 더미 컷 표식은 컷신 제외 범위입니다. 모든 모델 텍스처를 시각 검수했다는 뜻은 아닙니다.
- mdl/obj/E3obj042.txy의 소재 51개(고유 그림 50개)는 기계 구조와 가상 문자 장식입니다. 일본어 안내 그래픽은 확인되지 않아 원본을 보존합니다.
- mnu/pse의 TXT 6개는 #CUT/#ADX/#IMG_READ/#MESFILE로 음성·이미지·메시지를 연결하는 회고/오프닝 연출 스크립트입니다.
  이 스크립트는 Shift-JIS, 연결된 MES 6개는 EUC-JIS-2004로 읽히며, 일괄 인코딩 변경 대상으로 삼지 않습니다.
  컷신 파이프라인 제외 지시에 따라 해석/재구성 도구를 추가하지 않고 원본을 그대로 보존합니다.
- mnu/umn.bin과 skillbg.bin의 PXY/TXY에 포함된 텍스처 10개는 선·테두리·배경 효과입니다. 실제 팔레트와 좌표로 복원하여 확인했으며 번역 그래픽 도구를 추가하지 않았습니다.
- mnu/credit.bin은 SLPS 00a80b28이 읽는 회사/미들웨어 로고 JPEG 4개입니다. 일본어 안내 이미지가 아니므로 원본을 보존합니다.
- diskchg.bin은 SLPS 001b3df8이 읽는 배경 JPEG 1개와 음성 멤버 7개입니다. 앞서 잡힌 작은 JPEG 2개는 배경 파일 내부의 미리보기로, 독립 게임 화면이 아닙니다.
  배경에는 시온의 영문 이름/신장/체중이 작게 표시되며 일본어 교체 안내문은 없습니다. SLPS 001b3878이 별도로 읽는 discchg.txd에 실제 교체 안내가 있으며 기존 번역 파이프라인 대상입니다. 배경의 영문까지 이미지화 번역하는 도구는 현재 추가하지 않았습니다.
- mnu/monitor.bin의 이미지 4개는 컨트롤러 아이콘이고, 안내 문구는 기존 menutext 번역을 사용합니다.
- mg1/com/ModelExt의 TXY 55개는 소재 162개를 복원하여 확인했습니다. 블록·지형·기호·시작/도착점·배경 효과이며 읽을 수 있는 일본어 안내문은 없습니다. 흐린 문자 무늬도 배경 장식입니다. 이 모델 텍스처들에는 별도 번역 파이프라인을 추가하지 않았습니다.
- mnu/jp/icon.bin은 메모리카드 아이콘/제목 자료입니다. 제목은 SLPS의 별도 2바이트 변환 경로에서 덮어써지므로 일반 텍스트 치환 대상으로 처리하지 않습니다.
- 저장 제목 전용 이름을 메뉴 끝에 분리하는 선택 후처리 도구는 tools/elf/edit/Build_save_title.bat입니다. 완성된 menutext.txd를 드롭하면 현재 실행 파일 번역을 유지한 메뉴/SLPS 묶음을 만듭니다. 일반 X30/ELF 빌드와 ROM에는 자동 적용하지 않습니다. 반드시 같은 묶음의 메뉴와 실행 파일을 함께 사용해야 하며, 사용법과 시스템 글꼴 제약은 tools/elf/README.txt 및 SAVE_TITLE.txt를 참고하세요. 이름 TXT의 초기값은 원문이며 출시용 표기는 사용자가 결정합니다.
- menutext의 일반 빌드에는 16,384바이트 상한 검사를 적용했습니다. SLPS 내 ov01 로더가 menutext를 0x003C2040, 다음 umn.bin을 0x003C6040에 적재하므로 그 경계를 넘는 파일은 저장하지 않습니다.
- 현재의 빌드 검증은 게임 화면의 미번역 문구나 표시 문제까지 검사하지 않습니다. ROM 적용/게임 확인 결과가 있어야 후속 대상 판단이 가능합니다.
