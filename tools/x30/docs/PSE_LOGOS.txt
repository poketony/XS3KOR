PSE 작품 로고 PNG 편집 및 TM2 리빌드 (2026-10-24)

작업과 실행
- 작업 폴더: 0.X30/mnu/pse/kr. logo_ep1.png, logo_ep2.png, logo_pp.png를 그림 편집기로 수정합니다.
- 새 PNG 세 개는 일본판 원본에서 추출한 상태입니다. 로고를 자동 번역하거나 변경하지 않았습니다.
- 같은 폴더의 Build_PSE_logos.bat를 더블클릭하면 PNG 세 개를 모두 리빌드합니다.
- 원래 이름의 PNG 하나를 BAT에 드롭하면 그 로고만 리빌드합니다.
- 이름이 다른 PNG는 --asset logo_ep1, logo_ep2 또는 logo_pp로 대상을 지정합니다.
- CLI: 0.X30\mnu\pse\kr\Build_PSE_logos.bat "0.X30\mnu\pse\kr\logo_ep1.png" --check
- 다른 이름: Build_PSE_logos.bat --asset logo_ep2 "경로\수정본.png"
- Python: python -B tools/x30/build_pse_logos.py --asset logo_ep1 --check
- 입력은 저장소의 0.X30 또는 tools/x30 내부 PNG만 허용합니다. 상대 경로는 실행한 폴더 기준입니다.
- --check는 저장하지 않습니다. Python 3.10 이상과 Pillow가 필요합니다. XS3_NO_PAUSE=1이면 종료 대기를 생략합니다.

그림 규칙
- logo_ep1.png와 logo_ep2.png는 136x90, logo_pp.png는 128x90입니다. 크기를 바꾸지 마세요.
- 투명도가 있는 단일 PNG를 사용합니다. RGB 전용 이미지, 애니메이션, JPEG는 거부합니다.
- RGB는 변경 없이 기록하고, PNG 알파 0~255는 가장 가까운 게임 알파 0~128로 변환합니다.
  따라서 편집한 반투명 픽셀의 알파에는 양자화가 있습니다. 원본 추출 PNG는 바이트 그대로 왕복합니다.
- TM2 앞 64바이트의 헤더, 파일 크기, 픽셀 배열 순서는 그대로 유지합니다. 색상표나 크기를 재구성하지 않습니다.
- 배경 haikei.tm2에는 번역 문구가 없어 이 도구의 대상에 포함하지 않았습니다.

출력과 독립성
- 결과: 같은 작업 폴더의 logo_ep1.tm2.new, logo_ep2.tm2.new, logo_pp.tm2.new.
- 같은 폴더의 일본판 원본 TM2와 PNG를 직접 읽습니다. tools/x30/edit 사본은 없습니다.
- Extract_PSE_logos.batlock을 필요한 때만 .bat로 바꿔 원본 PNG를 추출하고 다시 잠급니다. 기존 PNG는 덮어쓰지 않습니다. --asset으로 하나를 선택하거나 --check로 저장 없이 원본 왕복을 검사할 수 있습니다.
- 작업 PNG, 기준 TM2, 실행 파일과 외부 ROM은 수정하지 않습니다. output은 사용자가 외부 X30_UNPACKED에 수동 적용합니다.
- 선택한 PNG를 모두 검사한 뒤 출력합니다. 오류가 나면 이전 output이 남아 있을 수 있으니 적용하지 마세요.

실행 코드 근거와 한계
- SLPS 00249168이 파일 크기에 맞춘 버퍼를 할당하고, 0024a4a8이 로고 이름을 선택합니다.
- 00248ad0은 파일 +0x10 + 그림 헤더 크기에서 픽셀을 읽습니다. 이 세 파일의 시작은 +0x40입니다.
- 원본 코드의 전송/표시 크기는 136x90으로 고정되어 있고, DMA/GIF 길이 0x7000은 로고 파일의 픽셀 크기보다 큽니다.
  특히 PP 파일의 폭 128과도 다릅니다. 이 도구는 그 기존 동작을 수정하거나 보정하지 않습니다.
- 기존 헤더와 파일 길이를 보존하는 픽셀 편집 도구입니다. 화면상의 PP 표시와 원본 전송 코드 문제를 해결했다고 주장하지 않습니다.
  실제 게임에서 투명도, 문구 가독성, 잘림을 확인해야 합니다.

검증
