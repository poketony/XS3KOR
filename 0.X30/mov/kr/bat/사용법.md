# 전투 자막 재인코딩 사용법

이 폴더의 자막 TXT를 **UTF-8**로 편집한 뒤 `Reencode_bat.bat`로 변환합니다.
컷신 자막과 같은 **한글 치환 -> EUC-JIS-2004** 방식을 사용합니다.

## 전체 변환

1. 수정한 TXT를 UTF-8로 저장합니다.
2. `Reencode_bat.bat`를 더블클릭합니다.
3. `BUILD SUCCEEDED`가 표시되었는지 확인합니다.

같은 폴더의 TXT 전체를 처리하며, 결과는 원래 이름 뒤에 `.new`가 붙습니다.
예: `CHRV_EVE0000.txt` -> `CHRV_EVE0000.txt.new`

## 선택 변환

TXT 하나 또는 여러 개를 선택해 `Reencode_bat.bat` 위에 드롭합니다.
드롭한 파일만 변환하며, 출력 위치와 파일명은 전체 변환과 같습니다.

## 저장 없이 검사

이 폴더에서 명령 프롬프트나 PowerShell을 열어 실행합니다.

```powershell
.\Reencode_bat.bat --check
.\Reencode_bat.bat .\CHRV_EVE0000.txt --check
```

첫 명령은 전체, 둘째 명령은 지정한 TXT만 검사합니다.
`CHECK SUCCEEDED`이면 검사를 통과한 것이며 `.new`는 생성하거나 갱신하지 않습니다.

## 주의사항

- 원본 작업 TXT는 덮어쓰지 않습니다. 다음 번역도 `.txt.new`가 아닌 UTF-8 `.txt`에서 합니다.
- 타이밍, 탭, 공백, 줄바꿈, 주석, 문장 부호, 문자 그대로의 `\n`을 유지합니다. UTF-8 BOM은 출력에서 제외합니다.
- 인코딩 후 파일 크기가 1,024바이트를 넘거나, 치환표에 없는 한글 또는 인코딩 불가 문자가 있으면 저장 전에 중단합니다.
- 선택한 파일을 모두 검사한 뒤 저장합니다. 이전과 결과가 같으면 기존 `.new`를 다시 쓰지 않습니다.
- 실패한 실행의 산출물은 적용하지 마세요. 이전 실행의 `.new`가 남아 있을 수 있습니다.
- 쓰기 중 오류나 강제 종료로 `.pending`이 남으면 원인을 확인한 뒤 다시 실행하세요.
- 외부 ROM 작업 폴더로 자동 복사하지 않습니다. 수동 적용할 때만 결과의 `.new`를 뺀 원래 이름으로 넣습니다.
- Python 3.10 이상이 필요하며 추가 패키지는 필요하지 않습니다. `.md` 안내 파일은 변환 대상이 아닙니다.
