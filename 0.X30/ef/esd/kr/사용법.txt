ESD 지역 진입 지명 이미지
========================

1. ce003_999.png처럼 ESD와 이름이 같은 PNG를 편집합니다.
2. Rebuild_esd.bat는 ESD와 같은 지명을 쓰는 맵 ESP를 함께 만듭니다.
   더블클릭하면 ESD 25개와 맵 ESP 45개를 처리합니다.
3. 한 PNG 또는 여러 PNG를 BAT에 드롭하면 해당 ESD와 연결된 맵만 만듭니다.
   ce003_999.png -> ce003_999.esd.new + ../../map/ef1220.esp.new + ../../map/ef1228.esp.new
4. 명령줄에서 Rebuild_esd.bat --check는 파일을 쓰지 않고 전체를 검사합니다.

256x32 크기와 투명도를 유지하세요. 원본이 검정 RGB와 단계별 알파로 구성된
합성용 마스크이면 글자 본체와 그림자를 모두 알파로 옮깁니다. 검정은 기존 알파를
유지하고, 회색 그림자는 밝기에 맞는 반투명 검정으로 바꿉니다. 변환식은
새 알파 = 기존 알파 * (255 - 회색값) / 255이며, 반올림한 뒤 원본 알파 단계에
맞춥니다. 흰 배경 위에서의 명암을 보존하며 그림자를 분리하거나 지우지 않습니다.
유색 입력은 임의로 변환하지 않고 중단합니다. 작업 PNG는 수정하지 않으며,
ESD/ESP 각각의 원본 팔레트도 보존합니다. 실제 다색 팔레트에만
투명색 포함 최대 16색의 전용 팔레트를 만들며, 완전 투명한 픽셀의 숨은 RGB는
색상 선택에서 제외합니다. quantized_pixels는 감색 또는 알파 단계에 맞춘 픽셀
수이며 palette_mode는 alpha_mask/rgba, palette_changed는 팔레트 갱신 여부입니다.
기존 팔레트로 정확히 표현되는 그림은 바이트 단위로 그대로 왕복합니다.
문구 외 애니메이션, 빛 효과, 다른 이미지, 헤더, 파일 크기는 바꾸지 않습니다.

여기의 .esd는 일본판 기준 원본입니다. PNG는 현재 ROM 작업물에서 가져왔으므로
이미 한글로 작업된 ce003_999의 '연방 궤도 우주 항구'도 보존되어 있습니다.
새로 자동 번역한 이미지는 없습니다. 원본 .esd와 PNG는 리빌드 시 수정하지 않습니다.

수동 적용: .new를 뺀 이름으로 외부 Xenosaga3/X30_UNPACKED/ef/esd/jp와
ef/esd/ce000 양쪽에 동일한 결과를 넣습니다. 두 경로의 일본판 원본 및 초기
작업본이 각각 바이트 동일함을 확인했습니다. 자동 복사하지 않습니다.
맵 결과는 .new를 뺀 이름으로 외부 X30_UNPACKED/ef/map에 수동 적용합니다.
맵 지명도 여기의 공통 PNG를 사용하므로 *.location.png를 따로 수정할 필요가 없습니다.
외부 ROM 폴더로 자동 복사하지 않습니다. 그쪽 ISO 빌드는 계속 독립적입니다.
같은 PNG를 쓰는 ESD와 맵 ESP는 같은 색/투명도로 변환합니다.
기준 알파 단계가 다른 ef0420도 팔레트를 보존한 채 같은 본체/그림자 마스크를 배치합니다.

원본 재추출: Extract_esd.batlock의 확장자를 .bat으로 바꿔 실행합니다.
기존 PNG가 하나라도 있으면 아무 파일도 덮어쓰지 않고 중단합니다.
작업본을 따로 보존한 뒤 필요할 때만 추출하세요. 추출 원문은 일본어입니다.
사용 후 확장자를 다시 .batlock으로 바꾸세요.

Python 3.10 이상과 Pillow가 필요합니다. 코드와 목록은 tools/x30에 있습니다.
codex-lab, 외부 ROM 폴더, 다른 저장소는 실행 시 필요하지 않습니다.
실제 게임 표시 검증은 별도입니다. 실패한 실행의 .new는 적용하지 마세요.
