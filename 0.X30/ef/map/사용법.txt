맵 ESP 내장 지역명 이미지
========================

공통 작업 PNG는 ../esd/kr/ce*.png입니다. ESD와 맵에 같은 지명을 사용합니다.
일상 작업은 ../esd/kr/Rebuild_esd.bat로 ESD와 맵 ESP를 함께 리빌드합니다.
Rebuild_map_labels.bat는 같은 공통 PNG를 읽되 맵 ESP 45개만 만듭니다.
공통 ce*.png를 드롭하면 그 지명을 쓰는 맵들만 처리합니다.
예: ce003_999.png -> ef1220.esp.new 및 ef1228.esp.new
기존 *.location.png는 원본 추출/대조용으로 남겨 두며 빌드 입력이 아닙니다.
*.location.png를 드롭하면 오류로 중단합니다. 공통 PNG를 편집하세요.
Rebuild_map_labels.bat --check는 저장 없이 검사합니다.

기준 ESP는 기존 저장소 파일을 그대로 사용합니다. 그중 5개에 이미 들어 있는
한글 지명도 PNG로 추출했으며 외부 ROM 작업물과의 일치를 확인했습니다.
ESD와 ESP의 내부 texture_name이 같은 항목을 연결하며 파일 번호로 추측하지 않습니다.
지명 이미지와 해당 전용 팔레트만 변경할 수 있습니다.
다른 이펙트, 애니메이션, 헤더, 다른 이미지의 팔레트와 파일 크기는 변경하지 않습니다.

이미지는 256x32이며 투명도를 유지해야 합니다. 기존 팔레트로 정확히 표현되지
않는 PNG는 전용 16색 팔레트를 새로 만들어 ESD와 같은 방식으로 반영합니다.
완전 투명한 픽셀의 숨은 RGB는 무시하며 투명 영역을 유지합니다.
quantized_pixels는 감색/알파 변환으로 달라진 픽셀 수이고,
palette_changed=True는 팔레트를 갱신했다는 뜻입니다. 오류 코드가 아닙니다.
출력 .new를 뺀 이름으로 외부 ROM 폴더의 X30_UNPACKED/ef/map에 수동 적용합니다.
공통 PNG는 저장소 안에서 직접 읽습니다. 외부 ROM 폴더를 빌드 입력으로 읽거나
자동으로 갱신하지 않습니다. 기준 ESP가 없거나 바뀌면 원본 해시 검사에서 중단합니다.

재추출은 Extract_map_labels.batlock을 .bat으로 바꾼 뒤 실행합니다.
기존 PNG가 하나라도 있으면 덮어쓰지 않고 전체 중단합니다. 먼저 작업 PNG를
따로 보관하세요. 재추출은 현재 기준 ESP 내용이며 반드시 일본어라는 뜻은 아닙니다.
사용 후 확장자를 다시 .batlock으로 바꾸세요.

이 폴더의 모든 ESP를 번역 자산으로 판정한 것은 아닙니다. 이번 도구는 실행 및
데이터 구조를 보존하면서 확인된 지역명 비트맵만 교체합니다. 게임 표시는 별도 확인이 필요합니다.
